🎬 Netflix Clone

A responsive clone of Netflix’s landing page, built using HTML and CSS. This project was created as a front-end practice to sharpen layout, styling, and responsive design skills by recreating the visual appeal of a popular streaming platform.

📌 About the Project

🔹 Focuses on UI replication only (no backend or streaming functionality)

🔹 Built with pure HTML and CSS

🔹 Fully responsive for different screen sizes

🔹 Includes navbar, hero section, FAQ accordion, and footer — just like Netflix!

🛠️ Tech Stack
	•	HTML5
	•	CSS

How to Run Locally

git clone https://github.com/asit2004/netflix_clone.git

cd netflix_clone

open index.html   # or just double-click the file
